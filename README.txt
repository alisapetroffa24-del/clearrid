# ✨ Clearid

**Clearid** — вебзастосунок, який допомагає швидше працювати з великими текстами та знаходити головну інформацію.

## ❗ Проблема
У великих текстах складно швидко знайти важливе, тому на їх читання та аналіз витрачається багато часу.

## 💡 Рішення
Clearid пропонує три основні функції:

1. ✂️ **Скоротити текст** — залишити головне.
2. 💡 **Пояснити простими словами** — зробити складну інформацію зрозумілішою.
3. 📌 **Витягти важливе** — знайти дати, терміни та основні факти.

## ⭐ Must Have
- Введення тексту вручну.
- Завантаження файлів `.txt`.
- Три функції обробки тексту.
- Відображення результатів.

## 🖥️ Технології
- Python
- Streamlit

## 🚀 Запуск проєкту

Встанови бібліотеки:
pip install -r requirements.txt

Запусти програму:
streamlit run app.py

## ⚙️ Стан проєкту
Зараз це інтерактивний прототип із демонстраційними результатами та заглушками замість AI-функцій. У майбутньому планується підключити штучний інтелект.
